## MODIFIED Requirements

### Requirement: 主市场上游生命周期
服务 SHALL 在应用开始接受 HTTP 流量前建立全部必需的主市场连接，并 SHALL 复用并发安全的主市场客户端资源。服务 MUST 跟踪真实连接状态，在连接断开后执行有界重连或主机故障转移，并在关闭时停止恢复活动并释放连接。

#### Scenario: 启动时连接主市场
- **WHEN** 应用启动且至少一个配置的主市场节点可用
- **THEN** 服务在开始接受 HTTP 流量前建立主市场连接

#### Scenario: 主市场启动连接失败
- **WHEN** 应用启动时没有配置的主市场节点能在期限内完成连接
- **THEN** 应用返回明确启动错误且不进入可接收流量的状态

#### Scenario: 主市场连接断开
- **WHEN** 已建立的主市场连接在查询期间发生可重试网络错误
- **THEN** 服务标记连接为不可用，并在配置的次数和期限内重新连接或切换节点

#### Scenario: 请求前检查主市场连接
- **WHEN** 主市场接口收到请求且对应连接当前不可用
- **THEN** 服务在调用业务协议前同步尝试恢复连接，恢复成功后执行请求，恢复失败则返回标准上游错误

#### Scenario: 首次调用底层主市场协议
- **WHEN** 应用启动后首次请求公告、财务或其他不会自行连接的底层主市场能力
- **THEN** 服务使用已建立的主市场连接执行调用，不得返回由未连接状态导致的错误

#### Scenario: 服务关闭
- **WHEN** 应用进入优雅关闭流程
- **THEN** 服务停止新的连接恢复活动、排空在途调用并关闭全部主市场连接

### Requirement: 主市场 HTTP 通用契约
主市场接口 SHALL 使用统一 JSON 成功与错误结构、请求 ID 和稳定错误码，SHALL 应用默认宽松且可配置的 CORS，并 SHALL 被机器可读 OpenAPI 文档完整覆盖。就绪检查 MUST 仅在全部必需的主市场连接真实可用时报告成功。

#### Scenario: 主市场上游超时
- **WHEN** 主市场上游未在配置期限内响应
- **THEN** API 返回 HTTP 504 和标准超时错误码

#### Scenario: 主市场连接不可用
- **WHEN** 请求前连接恢复失败且错误不是超时
- **THEN** API 返回 HTTP 502 和标准上游不可用错误码

#### Scenario: 主市场连接未就绪
- **WHEN** 必需的主市场连接未建立或已断开且尚未恢复
- **THEN** 就绪检查返回失败状态

#### Scenario: 发现主市场接口
- **WHEN** 客户端获取 OpenAPI 文档
- **THEN** 文档包含全部 `/api/v1/stocks` 稳定操作

### Requirement: 主市场连接可观测性
服务 SHALL 使用结构化日志记录主市场连接尝试、连接成功、连接失败、协议错误导致的断开、请求触发的重连和服务关闭。日志 MUST 包含协议类别和客户端组标识，错误日志 MUST 包含错误原因，且不得记录请求中的证券列表或上游原始响应内容。

#### Scenario: 主市场连接成功
- **WHEN** 启动连接或请求触发的重连成功
- **THEN** 服务记录包含 `protocol=main`、客户端组和当前地址的成功日志

#### Scenario: 主市场连接失败
- **WHEN** 主市场连接或重连失败
- **THEN** 服务记录包含 `protocol=main`、客户端组、尝试类型和错误原因的错误日志

#### Scenario: 主市场连接断开
- **WHEN** 可重试协议错误使主市场连接失效或服务关闭该连接
- **THEN** 服务记录断开原因和连接状态变化，不记录业务请求或原始响应数据
