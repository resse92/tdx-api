## Purpose

为 `gotdx` 支持的股票相关行情数据提供稳定且与编程语言无关的 HTTP 接口，并确保参数校验、响应、跨域访问和运行行为可预测。

## ADDED Requirements

### Requirement: 版本化 JSON API 契约
服务 SHALL 在 `/api/v1` 下公开稳定的股票行情 API，证券代码 `code` SHALL 使用 `<6 位数字>.SH` 或 `<6 位数字>.SZ` 格式通过查询参数或 JSON 请求体提供，板块代码 `board_symbol` SHALL 通过查询参数提供，二者均不得出现在接口路径中；服务 SHALL 使用统一的成功或错误响应结构返回 JSON，但明确记录的文件下载接口除外。

#### Scenario: 请求成功
- **WHEN** 客户端向受支持的 `/api/v1` 接口发送有效请求
- **THEN** 服务返回 2xx 响应，并在约定的成功响应结构中包含所请求的数据

#### Scenario: 路由不受支持
- **WHEN** 客户端请求不属于公共 API 的路由
- **THEN** 服务使用标准错误响应结构返回 HTTP 404

### Requirement: 主市场证券与行情访问
API SHALL 提供稳定的 `gotdx` 主市场能力，包括证券数量、按范围或分页查询证券列表、单个及批量行情快照，以及受支持主市场代码的详细股票行情。

#### Scenario: 查询证券列表
- **WHEN** 客户端提供有效的市场和分页范围
- **THEN** API 返回匹配的主市场证券及分页元数据

#### Scenario: 查询批量行情
- **WHEN** 客户端提供有效的带交易所后缀代码
- **THEN** API 返回与所请求证券对应的行情结果

### Requirement: 主市场时序与成交数据访问
API SHALL 提供稳定的 `gotdx` 股票和指数 K 线、K 线偏移、当前及历史分时或分笔图、图表采样、当前成交、历史委托和历史成交能力。

#### Scenario: 查询历史 K 线
- **WHEN** 客户端提供有效的证券、K 线类别、偏移量和数量
- **THEN** API 按上游顺序返回可用 K 线，并包含对应的市场和代码上下文

#### Scenario: 查询历史成交
- **WHEN** 客户端提供有效的证券、需要时提供日期、起始位置和数量
- **THEN** API 返回该请求可用的成交或委托记录

### Requirement: 主市场分析与事件访问
API SHALL 提供稳定的 `gotdx` 指数信息、指数动量、筹码分布、集合竞价、热门板块、异动、交易所公告、服务器信息和服务器心跳能力。

#### Scenario: 查询市场事件数据
- **WHEN** 客户端向集合竞价、热门板块、异动或公告接口提交有效参数
- **THEN** API 返回对应的上游记录，且不得静默替换为其他数据集

### Requirement: F10、财务与公司行为访问
API SHALL 提供稳定的 `gotdx` 聚合 F10、财务信息和除权除息信息，原始文件获取和解析 SHALL 由服务器内部处理。

#### Scenario: 查询 F10 信息
- **WHEN** 客户端向 F10 接口提供受支持的带交易所后缀股票代码
- **THEN** API 返回聚合 F10、财务或公司行为数据

#### Scenario: 原始文件接口不可访问
- **WHEN** 客户端请求文件元数据、文件下载或要求传入上游文件名
- **THEN** 服务返回 HTTP 404，且不调用 `gotdx` 文件方法

### Requirement: 仅提供沪深市场数据
API SHALL 对按证券查询只接受 `.SZ` 的深圳代码和 `.SH` 的上海代码，并由后缀推导 `gotdx` 所需市场；仅无 `code` 的全市场查询接受 `market=0` 或 `market=1`。API 不得公开扩展市场路由，并 SHALL 从包含 `Market` 字段的集合响应中移除所有非沪深记录。

#### Scenario: 拒绝非沪深市场
- **WHEN** 客户端提供非 `.SH`、`.SZ` 证券后缀，或在全市场接口提供其他市场值
- **THEN** 服务返回 HTTP 400，且不调用 `gotdx`

#### Scenario: 扩展市场路由不存在
- **WHEN** 客户端请求 `/api/v1/extended` 下的任意路由
- **THEN** 服务返回 HTTP 404

### Requirement: MAC 板块与股票访问
API SHALL 提供稳定的 `gotdx` MAC 能力，包括板块数量与列表、板块成分、成分排序、静态和动态成分行情、动态行情过滤、批量证券行情、可选日期的股票快照与成交、集合竞价、多日分时、股票摘要、资金流向、服务器信息、K 线偏移、市场监控、证券所属板块及统一证券 K 线；MAC 原始文件接口不得公开。

#### Scenario: 通过查询参数查询板块
- **WHEN** 客户端向固定板块成分或行情路径提供有效的 `board_symbol` 查询参数
- **THEN** API 使用该板块代码查询上游，且不注册包含板块代码的动态路径

#### Scenario: 使用动态字段查询板块成分
- **WHEN** 客户端提供有效的板块标识、分页、位图、排序和可选过滤参数
- **THEN** API 返回匹配的动态成分行情记录，并保留所请求的字段选择

#### Scenario: 查询统一 MAC 证券 K 线
- **WHEN** 客户端提供受支持的带交易所后缀证券代码、周期、偏移量和数量
- **THEN** API 返回请求范围内可用的 MAC 证券 K 线

### Requirement: 输入校验与请求边界
服务 MUST 在调用上游前校验必需标识、沪深市场、日期、业务枚举、分页和批量列表长度，并 MUST 对潜在的大型请求执行文档约定的上限。公共 API SHALL 只接受各接口文档明确列出的参数，未知参数 MUST 返回 HTTP 400。

#### Scenario: 请求参数无效
- **WHEN** 请求缺少必填值、包含无效枚举、日期格式错误或数值超出允许范围
- **THEN** 服务返回 HTTP 400 和字段级错误详情，且不调用 `gotdx`

#### Scenario: 协议参数不可注入
- **WHEN** 客户端提供 `start`、数字 `category`、`times`、位图、排序、过滤或其他未公开协议参数
- **THEN** 服务返回 HTTP 400，且服务器使用内部默认值调用 `gotdx`

### Requirement: 精简的业务参数
API SHALL 使用 `offset` 和 `limit` 表达分页，使用字符串 `period` 表达 K 线周期，使用字符串 `adjust` 表达复权方式，并 SHALL 使用仅含带交易所后缀 `code` 的 `symbols` 对象数组表达批量证券；服务 SHALL 为可选参数提供安全默认值。

#### Scenario: 使用默认参数
- **WHEN** 客户端省略可选的 `offset`、`limit`、`period` 或 `adjust`
- **THEN** 服务分别使用接口约定的默认分页、`daily` 周期和 `none` 复权方式

#### Scenario: 批量查询证券
- **WHEN** 客户端提交每项仅含 `.SH` 或 `.SZ` 后缀 `code` 的 `symbols` 数组
- **THEN** 服务校验每个证券、推导其市场并执行批量行情查询，不接受项内 `market` 或平行的 `markets` 和 `codes` 数组

### Requirement: 统一的上游错误处理
服务 SHALL 将上游连接失败、超时、数据不可用和内部失败映射为稳定错误码，并保留有用的诊断上下文，同时不得泄露堆栈信息或敏感数据。

#### Scenario: TDX 上游超时
- **WHEN** 选中的上游未在配置的超时时间内响应
- **THEN** API 返回 HTTP 504 和标准超时错误码

#### Scenario: TDX 上游不可用
- **WHEN** 没有任何已配置的上游主机能够处理请求
- **THEN** API 返回 HTTP 502 或 503，以及表示可重试上游故障的错误码

### Requirement: 跨域访问
服务 SHALL 对 API 响应应用 CORS 响应头，SHALL 默认允许所有来源，并 SHALL 支持通过运行时配置限制允许的来源、方法和请求头。

#### Scenario: 默认跨域请求
- **WHEN** 浏览器使用默认配置从任意来源发送有效请求或预检请求
- **THEN** 服务返回允许该跨域操作的响应头

#### Scenario: 来源受限
- **WHEN** 请求来源不在配置的白名单中
- **THEN** 服务不向该来源授予跨域访问权限

### Requirement: 健康检查与 API 发现
服务 SHALL 提供存活和就绪检查接口，并 SHALL 发布机器可读的 OpenAPI 文档，覆盖每个稳定公共接口及其请求和响应结构。

#### Scenario: 服务已就绪
- **WHEN** HTTP 服务正在运行且必需的上游客户端配置可用
- **THEN** 就绪检查接口返回成功状态

#### Scenario: 发现公共接口
- **WHEN** 客户端获取 OpenAPI 文档
- **THEN** 文档描述服务公开的全部稳定股票相关路由

### Requirement: 受管理的上游生命周期
服务 SHALL 复用并发安全的上游客户端资源，使用可配置的主机池和超时，对可安全重试的操作尝试重连或故障转移，并在优雅关闭期间先停止接收新任务，再关闭上游连接。

#### Scenario: 主节点失败
- **WHEN** 可安全重试的请求在选中主机上遇到连接失败
- **THEN** 服务在返回上游错误前尝试有次数上限的重连或主机故障转移

#### Scenario: 服务关闭
- **WHEN** 进程收到终止信号
- **THEN** 服务在配置的期限内排空正在处理的 HTTP 请求并关闭全部上游连接
