## 背景与原因

`gotdx` 作为 Go 库提供了广泛的 TDX 股票行情访问能力，但使用者目前必须自行嵌入 Go 代码并管理协议连接。通过独立的 Gin 服务，可以将这些能力转化为跨语言调用、接口一致且可重复部署的 HTTP API。

## 变更内容

- 使用 Gin 和 `github.com/bensema/gotdx` 初始化 Go 应用。
- 为全部稳定的 `gotdx` 股票相关能力提供版本化 JSON 接口，包括主市场证券与行情、K 线与分时、成交与市场信号、F10/公司资料与股票文件、扩展市场股票数据，以及 MAC 板块与股票数据。
- 提供统一的请求校验、响应结构、上游错误映射、健康检查和 API 文档。
- 支持可配置的跨域请求，默认启用宽松 CORS 供外部调用。
- 在服务内部管理共享 `gotdx` 客户端、主机选择、超时、重连和优雅关闭。
- 提供自动化多阶段 Docker 构建及基于环境变量配置和健康检查的 Docker Compose 部署。
- 首版稳定公共契约不包含商品专用 API、ICFQS 原始 API 以及实验性或兼容性协议方法。

## 能力范围

### 新增能力

- `stock-market-http-api`：通过版本化 Gin HTTP 接口提供稳定的 `gotdx` 主市场股票、扩展市场股票、F10/文件和 MAC 股票行情查询，并包含参数校验、CORS、统一 JSON 响应和服务健康状态。
- `containerized-service`：提供可重复构建的多阶段 Docker 和 Docker Compose 部署，支持运行时配置、健康检查和优雅生命周期管理。

### 修改能力

无。

## 影响范围

- 在当前仓库中新增 Go 模块和 HTTP 服务应用。
- 新增 Gin、`gotdx`、CORS 中间件和 API 文档相关依赖。
- 引入版本化公共 HTTP 路由，以及连接 TDX 上游服务的出站 TCP/HTTP 请求。
- 新增 Docker 构建和 Compose 部署文件、环境变量示例、测试及运维文档。
